# AGRIVIL — Master Mobile UI Reference

Figma master file: https://www.figma.com/design/nyNeNpl6sFUGWacwMPyXGi

This editable Figma file is the visual source of truth for Agrivil mobile UI. It contains individually named 390×844 reference frames. Reproduce design intent, hierarchy, spacing rhythm, typography and information density; do not blindly copy canvas coordinates.

The current Figma workspace has a Starter/View seat limitation, so references are organized as named frames rather than relying on one page per app section.
