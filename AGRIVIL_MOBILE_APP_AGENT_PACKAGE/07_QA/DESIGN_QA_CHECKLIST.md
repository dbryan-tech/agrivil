# DESIGN + UX QA CHECKLIST

## Visual
- [ ] Screens match approved Agrivil mockups.
- [ ] Cream canvas is dominant.
- [ ] Green is reserved for primary actions/active states.
- [ ] Brown supports hierarchy.
- [ ] Orange is restrained.
- [ ] No accidental gradients.
- [ ] No excessive glassmorphism.
- [ ] No emoji-based UI.
- [ ] Cards are used selectively.
- [ ] Images have consistent cropping.

## Typography
- [ ] Headings are clearly distinct.
- [ ] Body text is readable.
- [ ] Prices stand out appropriately.
- [ ] Secondary text is not too light.
- [ ] Labels use consistent casing.

## Interaction
- [ ] Tap targets are comfortably sized.
- [ ] Pressed/disabled states exist.
- [ ] Loading exists.
- [ ] Error exists.
- [ ] Empty state exists.
- [ ] Success state exists.
- [ ] Destructive actions are confirmed where appropriate.

## Commerce
- [ ] Variable-weight products work.
- [ ] Low stock works.
- [ ] Out-of-stock works.
- [ ] Price changes are represented.
- [ ] Cart totals update correctly.
- [ ] Delivery fee is visible.
- [ ] GhanaPostGPS is supported.
- [ ] Delivery slot selection works.
- [ ] MoMo and card options are represented.

## Orders
- [ ] Order lifecycle is represented.
- [ ] Tracking is understandable.
- [ ] Delivery estimate is visible.
- [ ] Proof of delivery can be surfaced.
- [ ] Issue/refund states are handled.

## Farmer
- [ ] Farmer profile is usable.
- [ ] Farm story/gallery can be viewed.
- [ ] Products are linked to the farmer.
- [ ] Farmer dashboard is simpler than consumer UI.
- [ ] Ledger and payout are clear.

## Accessibility
- [ ] Contrast is acceptable.
- [ ] Text is scalable.
- [ ] Icons have accessible labels.
- [ ] Colour is not the only status signal.
- [ ] Form errors are announced clearly.
