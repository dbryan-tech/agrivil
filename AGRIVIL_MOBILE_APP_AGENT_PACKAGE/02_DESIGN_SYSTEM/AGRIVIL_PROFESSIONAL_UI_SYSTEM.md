# Agrivil Professional UI System

## Core principle
Use the least visual machinery needed to communicate the relationship between content and action.

## Typography
Primary UI: Manrope. Use Regular for body, SemiBold for labels/meta, Bold for primary hierarchy and prices. Instrument Serif is a rare editorial accent only. Do not default to Inter without a documented reason.

## Working type scale
30/36 display; 26/32 screen title; 20/26 section title; 17/23 prominent item; 15/22 body; 13/18 supporting; 12/16 metadata; 11/14 caption.

## Color
Cream #F4F1EA; Forest #1E5D3B; Deep forest #144028; Earth brown #2B1F17; Muted text #6E6A63; Harvest orange #E67A2E; Earth gold #8A6B3D; Line #DED8CA; White #FFFFFF.

## Surfaces
Default canvas: cream. Primary content surface: open canvas. Secondary surface: white with subtle border only when separation is necessary. Image surface: full-bleed or edge-aligned when appropriate.

## Interaction
Primary actions use forest green. Secondary actions are often text-based. Destructive actions use semantic red only when necessary.

## Layout
390×844 reference viewport. 24px default horizontal content edge, reduced only when composition benefits. 4px spacing rhythm with contextual rather than mechanical application.

## Anti-patterns
No glassmorphism. No emoji UI. No gradient-heavy UI. No card-inside-card. No universal pill buttons. No generic three-column feature grids. No decorative animation. No huge whitespace created by default padding.
