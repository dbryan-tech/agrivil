# AI AGENT HANDOFF PROMPT — AGRIVIL MOBILE APP

Build the Agrivil mobile marketplace using this package as the product/design contract.

Before coding:
1. Read `README.md`.
2. Read `01_CORE/AGENT_INSTRUCTIONS.md`.
3. Read `02_DESIGN_SYSTEM/DESIGN_SYSTEM.md`.
4. Read `03_APP_ARCHITECTURE/APP_ARCHITECTURE.md` and `NAVIGATION_RULES.md`.
5. Read `04_SCREEN_SPECS/SCREEN_INVENTORY.md`.
6. Review every file in `08_REFERENCES/generated_mockups/`.
7. Review the supplied website/reference images in `08_REFERENCES/brand_website/`.
8. Read the project requirements PDF in `08_REFERENCES/`.

Then:
- establish the theme tokens
- establish navigation
- create reusable components
- implement consumer flows
- implement farmer flows
- add all important state variants
- connect the data layer through service abstractions
- verify against the mockups

Never create a visual style that conflicts with the references just because a framework defaults to it.

Do not stop at static screens. Build interaction and state logic.

At every milestone, compare the implementation visually with the matching reference image and correct discrepancies.
