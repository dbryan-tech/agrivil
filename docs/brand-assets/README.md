# AGRIVIL Brand Identity Master — Concept 01

This package develops the selected Concept 01 identity into a usable brand system.

## Included
- Primary / secondary / reversed / monochrome logos
- Standalone mark and app icon
- Favicon set
- Social, OG, LinkedIn, X/Twitter, website and mobile banners
- Business card, letterhead, email signature and invoice header
- UI icon set
- Brand pattern
- Logo usage board
- AI-generated application/identity reference boards
- Brand identity guide (Markdown + PDF)
- Asset manifest
- Original selected concept reference

## Core concept
Sun + cultivated field contour bands. This was chosen because it communicates harvest, land, growth and movement without relying on the overused leaf/tree/barn/agriculture clichés.

## Important
SVG files are the master vector assets; PNGs are convenience exports. Use SVG wherever the platform supports it. For app icons and favicons, use the purpose-built standalone mark rather than shrinking the full wordmark.

## Brand line
Farm Fresh. Market Smart. Delivered with care.
