# AGENT ACCEPTANCE CRITERIA

The implementation is not complete until:

1. All major consumer screens in `04_SCREEN_SPECS/SCREEN_INVENTORY.md` exist or are intentionally marked out of scope.
2. The consumer navigation works end-to-end.
3. A user can discover a product, inspect it, add it to cart, provide a GhanaPostGPS address, choose delivery, choose payment, and reach confirmation in a coherent flow.
4. Order tracking represents the defined order states.
5. Farmer profiles connect to their products.
6. Recipes and bundles have commerce links where defined.
7. Farmer onboarding and core farmer portal flows exist.
8. Empty/error/loading/success states are designed.
9. The visual language remains consistent across the app.
10. The app does not regress into excessive cards, glassmorphism, emoji or decorative UI.
11. The final implementation is compared against every supplied mockup.
12. The final app remains usable on smaller Android screens and slower connections.
