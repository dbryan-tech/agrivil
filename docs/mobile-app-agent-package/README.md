# AGRIVIL MOBILE APP — DESIGN + BUILD AGENT PACKAGE

## Purpose
This package is the single design/UX/product reference for building the Agrivil mobile marketplace app.

The app is a premium mobile storefront for farm-fresh products in Ghana, with supporting farmer, delivery, order, recipe, bundle/subscription, and account experiences.

## Primary design target
The interface must feel like one cohesive Agrivil product:
- premium, modern, clean, editorial
- Apple/Google level restraint and clarity
- warm agricultural character rather than generic grocery-app styling
- cream/off-white canvas, earthy dark brown typography, natural greens, restrained orange accent
- photography carries much of the visual identity
- minimal shadows, minimal floating containers, minimal glassmorphism
- no decorative emoji use
- avoid card-heavy UI; use grouping, dividers, whitespace and full-bleed imagery where appropriate

## Critical rule
The generated mockups are the visual source of truth for composition, hierarchy, spacing, component density, and interaction patterns. Where the written guide and a later approved mockup disagree, the latest approved mockup wins.

## Product scope
Consumer:
Onboarding → Shop → Product → Cart → Checkout → Orders/Tracking → Discover → Farmers → Account

Farmer:
Farmer onboarding → Dashboard → Products → Inventory → Orders → Earnings
